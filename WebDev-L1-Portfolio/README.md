## About the Project

This portfolio presents my introduction, technical skills,
selected projects, academic background and contact information.

The website follows a Dark Luxury visual concept with a
charcoal background, champagne-gold accents and ambient
gold lighting from both sides.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Add your photo to the images folder.
4. Name your photo profile.jpg.
5. Open index.html using Live Server.
6. View the portfolio in your browser.
